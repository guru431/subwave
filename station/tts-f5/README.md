# F5-TTS — общая TTS-служба gpu-host

Замена Chatterbox. Спека: [2026-09-23-tts-f5-migration-design.md](../docs/specs/2026-09-23-tts-f5-migration-design.md).
Движок — F5-TTS в русском дообучении ESpeech-TTS-1 RL-V2 (fp16 safetensors, 643 МБ).

## Ручки

| Ручка | Клиент | Контракт |
|---|---|---|
| `GET /health` | мостик станции, пульт gpu-ctl | `{"ok":true,"model_loaded":true,…}` после загрузки модели |
| `POST /v1/audio/speech` | мостик станции (`:4124`) | JSON `{input, voice?}` → WAV |
| `POST /speak` | шлюз `/speech/tts` | JSON `{text, voice?}` → WAV |
| `POST /clone` | digital_me `tts.py --local` | multipart `{text, ref_text, ref_audio}` → WAV |

Выход — WAV PCM 16 бит, моно, 24 кГц. Громкость эфира выравнивается до −17 dBFS с
потолком пика; `/clone` отдаёт родную громкость. Неизвестный голос даёт `ru-host`
и заголовки `X-TTS-Fell-Back*`.

Ударения ставит RUAccent, но всё вне её белого списка (латиница с диакритикой,
украинские буквы, `…`, `–`, `%`, `/`, `&`, `№`, `"`) она молча удаляет — такие места
идут к F5 мимо неё, нетронутыми (`f5_accent.SKIP_REGEX`). Латиница, которую F5
коверкает, пишется русскими буквами до RUAccent — `f5_text.PRONUNCIATION` («AI» →
«эй ай», «Metallica» → «Металлика»).

**Числа — словами, тоже до RUAccent** (`f5_numbers`, склоняет num2words): цифры ESpeech
читает как придётся, а контроллер с выставленным `persona.language` отдаёт годы, `%` и
`°` как есть. Падеж берётся из соседних слов, морфологии нет: «в 1969 году» —
«шестьдесят девятом», «1960-х» — «шестидесятых», «9 октября» — «девятое», «в 1988» —
«восемьдесят восьмом», «5%» — «пять процентов», «−3 °C» — «минус три градуса по
Цельсию», «2 минуты» — «две». Число рядом с латинским словом («Maroon 5», «2 Minutes
to Midnight») не трогается — его читает словарь коллекции.

**RUAccent 1.5.8.3 поправлена в `f5_accent`**, а не в пакете (корпус 269 реплик
ведущей, 2026-09-23):

| Беда RUAccent | Что было в эфире | Правка |
|---|---|---|
| Модель омографов tiny2.1 выбирает почти наугад (вероятности около 0.5) | «на связ+и» ×8, «рук+и не дошли», «ни облак+а» | `OMOGRAPH_MODEL = "turbo3.1"` — модель из примера ESpeech |
| Пакетный `classify` нормирует softmax по всей матрице, а не по строке | «у кого-то дорог+а из офиса» | `_row_softmax` |
| Омограф ищется как написан: слово с заглавной идёт мимо модели | «Сектор+а Газа», «К+ому-то», «Тон+и» | `_homographs_any_case` |
| Модель ё-омографов ставит ё, где его нет | «ещё дал+ёко», «само+ё время», «на н+ёбе» | не грузится; буква автора — как написана, словарь однозначных ё работает |
| Пометки «нужно ли ударение» съезжают после «»,» | «восемьдесят» без знака | `usage_by_words` |

Где ошибается и turbo3.1, прочтение закрепляется — по слуху владельца и по аудиту:
ошибка словаря — `STRESS_OVERRIDES` («глуш+ите»), омограф с одним прочтением в речи
ведущей — `HOMOGRAPH_OVERRIDES` («проб+ило», «началс+я»), устойчивое сочетание —
`PHRASE_STRESS` («р+уки вв+ерх», «ни +облака»). После любой правки — аудит:

    D:\Temp\f5-probe\venv\Scripts\python.exe <gpu-ssd>\LLM\docker\f5-tts\app\tools\stress_audit.py corpus.json

Он начинает с эталона — реплик эфира, на которых ударения уже были неверны; промах
хоть в одной — код выхода 1, образ не собирать. Корпус — ответы LLM ведущей из
журналов событий станции: `python3 tools/stress_corpus.py > corpus.json` на Debian.

**Словарь ударений — в SQLite, без него служба не стартует.** 3.2 млн словоформ в dict
Python занимали 661 МБ из 0.9 ГБ RUAccent, и turbo3.1 (403 МБ) в лимит 3 ГБ не
помещалась. База собирается из `accents.json.gz` на хосте, до выкатки образа:

    D:\Temp\f5-probe\venv\Scripts\python.exe <gpu-ssd>\LLM\docker\f5-tts\app\tools\accents_db.py

**Паузы ставятся явно.** Внутри одного куска F5 сам решает, где дышать, и запятые с
двоеточиями проглатывал. Реплика режется на единицы (`f5_text.pieces`): предложения и
части по двоеточию, точке с запятой и тире; по запятым не режется — интонация.
Между кусками — тишина: 450 мс после предложения, 250 на тире и двоеточии, 150 на
запятой при дорезке по пределу F5; края каждого куска подрезаются по −45 dB.

**Эталон `/clone` не касается диска:** синтез идёт мимо `F5TTS.infer` (тот пишет
копию эталона во временный файл и не удаляет), а порог Starlette, после которого
загрузка сбрасывается на диск, поднят до потолка тела запроса (11 МиБ): эталон
чуть больше предела в 10 МиБ ручка отвергает уже после разбора формы.

## Размещение на gpu-host

    <gpu-ssd>\LLM\docker\f5-tts\
      app\          контекст сборки: этот каталог без tests и voices, плюс
                    ruaccent-koziev\ — koziev из пакета ruaccent венва SuperTonic
                    (в колесе его нет, RUAccent ищет его в каталоге пакета, а не в
                    workdir; образ кладёт его в пакет и проверяет при сборке)
      models\       espeech\ (fp16 safetensors + vocab.txt), vocos\
      ruaccent\     модели RUAccent (омографы turbo3.1; tiny2.1 — для отката на
                    образ f5-tts:pre-stress-2026-09-23) и dictionary\accents.sqlite
                    (tools/accents_db.py), монтируются на запись
      voices\       пары <id>.wav ≤12 с + <id>.txt; источник — <share>/radio/voices/f5/, в git их нет
      voices-src\   исходные записи, из которых резались эталоны

Compose слота — у пульта: `llm_routers/gpu-ctl/deploy/compose/tts.yaml`; поднимает
и гасит службу только пульт (`/ensure-up?slot=tts`). Слот резидентный: эфир на F5 с
2026-09-23 15:19 (первая попытка 13:50–14:08 откачена — модель шипела из-за конфига,
см. ниже). `mem_limit: 3g` и `memswap_limit: 3g` — место Chatterbox в ВМ Docker, своп
ВМ почти всегда полон. RUAccent грузится без RuleEngine (0.87 ГБ, `process_all` его
не вызывает), без модели ё-омографов и со словарём в SQLite — не возвращать: после
синтеза анонимной памяти 2.33 ГиБ (было 2.74 с tiny2.1 и словарём в dict, замер
2026-09-23), остальное до лимита занимает файловый кэш, который ядро отдаёт.

## Мостик эфира

Станция ходит не сюда, а в мостик `tts-bridge` на `:4124` (очередь, повторы 5xx,
аренда слота `tts`). Код — `station/tts-bridge/bridge.py`, на gpu-host его побайтовая копия в
`<gpu-ssd>\LLM\docker\tts-bridge\`; контейнер создаёт [tts-bridge-run.ps1](tts-bridge-run.ps1)
(запускать на gpu-host, `-Root <каталог мостика> -Source <bridge.py>`): `UPSTREAM=http://host.docker.internal:4126`,
`GPU_CTL_SLOT=tts`, токен пульта — из окружения старого `chatterbox-bridge`. Старый
мостик на Chatterbox остановлен, а не удалён — это откат до этапа 5а спеки.

## Сборка

`docker build` по SSH на gpu-host не работает (кредхелпер Docker Desktop в
session 0) — сборка идёт временной задачей планировщика в интерактивной сессии:

    $a = New-ScheduledTaskAction -Execute 'powershell.exe' -Argument '-NoProfile -ExecutionPolicy Bypass -File <gpu-ssd>\LLM\docker\f5-tts\app\build.ps1 -Root <gpu-ssd>\LLM\docker\f5-tts'
    $p = New-ScheduledTaskPrincipal -UserId 'Administrator' -LogonType Interactive -RunLevel Highest
    Register-ScheduledTask -TaskName 'TmpF5Build' -Action $a -Principal $p -Force
    Start-ScheduledTask -TaskName 'TmpF5Build'
    # ждать строки "exit …" в <gpu-ssd>\LLM\docker\f5-tts\build.log, затем:
    Unregister-ScheduledTask -TaskName 'TmpF5Build' -Confirm:$false

## Голоса

`tools/make_voice.py <запись.wav> <имя> <каталог>` режет эталон ≤12 с по последней
паузе и снимает транскрипт whisper-small; транскрипт проверить глазами — F5
выравнивает эталон по тексту. Готовая пара кладётся в `<share>/radio/voices/f5/` (в git
эталонов нет) и копируется в `<gpu-ssd>\LLM\docker\f5-tts\voices\`. Имя голоса — только ASCII: оно едет
в заголовке `X-TTS-Voice-Used`, а заголовки HTTP — latin-1; с другим именем служба
не стартует. Неизвестное имя в запросе попадает в `X-TTS-Fell-Back-Reason`
экранированным (`json.dumps`), поэтому опечатка в чужой раскладке тоже даёт голос
по умолчанию, а не 500.

## Латиница: словарь коллекции

ESpeech — русская модель и латиницу читает русскими правилами: «Wasting My Hate» →
«Востинг Майхэд», «Dire Straits» → «Даррис Тредс» (эфир 23.09). Поэтому латинские
исполнители и названия песен коллекции заменяются русскими буквами с ударением по
словарю [`pronunciation.json`](pronunciation.json) (`f5_text.cyrillize`): фраза целиком
прежде отдельных слов, регистр и вид апострофа не важны. Замена идёт **после** RUAccent:
«+» словаря, попав к ней, выключил бы разметку всей реплики, а латиницу она не трогает.
Прежний `f5_text.PRONUNCIATION` («AI», «Metallica») работает как раньше — до RUAccent.

Словарь собирает [`tools/pronunciation.py`](tools/pronunciation.py): `export` выгружает
из `catalog.db` латинские имена (у названия — исполнитель как подсказка языка), LLM
транскрибирует их по правилам ниже, `build` проверяет ответы (латиница, «+» не перед
гласной, два «+» в слове — запись отбрасывается) и выводит словарь слов из пар
«фраза → транскрипция». 28.09 транскрибировали четыре субагента Claude: 2352 фразы,
отброшена одна. Жалобы владельца и имена вне коллекции — руками в
[`tools/pronunciation-extra.json`](tools/pronunciation-extra.json), эти записи важнее LLM.

Правила транскрипции: как прочёл бы вслух русский ведущий, устоявшееся написание для
известных имён; язык — по имени (итальянское по-итальянски); «+» перед ударной гласной
в слове из двух и больше гласных, в односложном и перед «ё» — нет; одно слово на слово
источника; `&` → «и», `feat.` → «фит»; аббревиатуры по буквам через дефис.

Новые исполнители в коллекции — повторить `export` и `build` и пересобрать образ:
словарь лежит в образе (`COPY … pronunciation.json`).

## Конфиг модели и проверка речи

ESpeech-TTS-1 RL-V2 грузится с конфигом **`F5TTS_v1_Base`** (умолчание `F5_MODEL`).
С `F5TTS_Base` размеры сети те же, веса грузятся без ошибки, но из-за
`text_mask_padding` и `pe_attn_head` модель выдаёт шипение вместо речи — 2026-09-23
эфир 18 минут шёл с хрипами, а `smoke.py` отвечал OK: он проверяет HTTP и формат, не
смысл. Перед переключением эфира каждую пробную реплику прогонять через
[tools/check_speech.py](tools/check_speech.py) (whisper-small, код 1 — если совпало
меньше 40% слов; чистая речь даёт 47–70%, потому что whisper пишет числа цифрами и
коверкает латиницу, шум — около нуля):

    D:\Temp\f5-probe\venv\Scripts\python.exe tools\check_speech.py speak.wav --expect "Проверка связи."

## Проверка без карты

`F5_ENGINE=dry` подменяет модель тоном: проверяются HTTP, голоса, RUAccent офлайн
и путь `/clone` в малой памяти. Разовые контейнеры на gpu-host — только с `--memory`
и без `--gpus`: на карту служба выходит только через пульт.
