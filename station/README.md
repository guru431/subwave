# station — что добавляет этот форк SUB/WAVE

Форк [perminder-klair/subwave](https://github.com/perminder-klair/subwave) для
домашней станции «AI радио». Дерево апстрима правится только коммитами фич
(`feat|fix(controller|web): …` поверх тега апстрима); всё, чего у апстрима нет
вовсе, лежит здесь, в `station/`.

## Что добавлено

- **Русский интерфейс и ведущая.** Перевод плеера, русские готовые ответы на заказ,
  кириллица в жанрах, персона и правила дома для русского эфира.
- **Чат-комната с push.** Отдельный контейнер ([`room/`](room/README.md)): слушатели
  пишут из плеера, ведущая отвечает голосом в эфире; Web Push о важном — и при
  закрытой вкладке.
- **Точный заказ по `songId`.** Ящик заказа сверяет набранное с коллекцией, и заказ
  встаёт перед несданными авто-пиками.
- **Глубина очереди** (`queue.lookahead`): админка видит несколько треков вперёд, а
  в Liquidsoap по-прежнему уходит один.
- **Дизлайки слушателей** — только сигнал владельцу: предложения на вкладке Blocked.
- **Блокировка по папкам** коллекции и жанры папок (поле правила `folder`).
- **TTS-мостик и служба F5** ([`tts-bridge/`](tts-bridge/README.md),
  [`tts-f5/`](tts-f5/README.md)): Remote-контракт subwave поверх OpenAI-совместимых
  движков, очередь в один синтез, аренда слота GPU.
- **Нормализатор громкости** ([`loudness/`](loudness/README.md)): замер каждого
  трека целиком (EBU R128) в `library.db` станции.
- **Настройка воспроизводимо** ([`onboard/`](onboard/onboard.py)): мастер и точечные
  патчи настроек со сверкой чтением обратно.

Что изменено в контроллере и вебе и почему — `docs/controller-changes.md`,
`docs/web-changes.md`; вердикты переноса на новую версию апстрима —
`docs/port-*.md`.

## Раскладка

| Каталог | Что |
|---|---|
| `room/` | чат-комната; своя копия `normalize.py` |
| `tts-bridge/` | мостик Remote-контракта (`bridge.py`), подготовка эталонов (`prep_voice.py`) |
| `tts-f5/` | служба F5-TTS: сервер, ударения, утилиты (эталонов голосов в git нет) |
| `loudness/` | `measure.py`, `apply.py`, `voice_chain.py` и оркестратор `run.py` |
| `onboard/` | `onboard.py`, патчи настроек, промпт персоны |
| `skills/` | навыки ведущей `chat` и `curiosity` |
| `deploy/` | override compose, Caddyfile, шаблон конфига Apache, robots, правила блокировки, `.env.example` стека |
| `docs/` | развёртывание, грабли станции, изменения форка, спеки и планы |
| `tests/` | pytest станции |
| `tools/` | обезличиватель, сторож памяти, доставка ревизии на хост |
| `run-tests.sh` | тесты контроллера в собранном образе на хосте станции |

## Как развернуть

[`docs/deploy.md`](docs/deploy.md): стек subwave в Docker с нашими образами
`controller`/`web`, комнатой и своим Caddyfile; значения конкретной установки —
`.env` стека и `station/.env` (шаблоны — `deploy/.env.example`, `.env.example`).

## Как тестировать

```bash
pip install --group station/pyproject.toml:test   # зависимости набора, pip ≥ 25.1
cd station && python -m pytest          # быстрый набор станции
bash station/run-tests.sh --patch       # тесты наших фич контроллера в образе
bash station/run-tests.sh               # весь набор контроллера
```
