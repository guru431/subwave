# Блокировка эфира по жанрам и папкам — дизайн

Дата: 2026-09-23
Статус: **замысел**, к исполнению.

Во вкладке станции **Admin → Library → Blocked** («never plays») уже можно запретить эфир
треку, альбому, артисту, а правилами — жанру, тегу, настроению, плейлисту. Владелец хочет
запрещать **жанры и папки коллекции**, причём жанр трека берётся из тега, а у трека без
тега — по его папке.

Шире — жанровые передачи по расписанию и жанровые плейлисты в Navidrome — обсуждалось в
той же сессии и отложено: эта спека — первый шаг.

**Контекст, который здесь не повторяется:** стек станции —
[`station/docs/deploy.md`](../../../station/docs/deploy.md), патч контроллера —
[`station/docs/controller-changes.md`](../controller-changes.md), патч
веба — [`station/docs/web-changes.md`](../web-changes.md).

## 1. Заказ

Решения владельца от 2026-09-23:

| # | Что |
|---|---|
| 1 | Правило **Genre** блокирует и кириллические жанры (`Рок`, `Поп`, `Шансон`, `Детские`) |
| 2 | Жанр трека — из тега; если тега нет — жанр, назначенный его папке |
| 3 | Новое правило **Folder**: папка со всем содержимым |
| 4 | Папки выбираются **деревом** с поиском |
| 5 | `Сборки` блокируется целиком: там дубли, а «Детские песни из мультфильмов» и «Июль 2023» в эфире тоже не нужны |
| 6 | Жанры папок: `!Помойка русская` → Поп, `!Помойка Русский Рок` → Рок, `!Помойка зарубежная` → Pop + Rock |

Предложенные по умолчанию и принятые: `Classic` → Classical, `СЛОТ - ОркестрА` → Рок,
`Юля Кошкина` — без жанра, пока владелец не назначит.

## 2. Что показала разведка

Апстрим `subwave` v1.8.0, исходники живого контейнера `sub-wave-controller`; наш
`controller-ru.patch` этих файлов не касается.

**Правила уже есть и проверяются везде.** Поля — `tag`, `genre`, `mood`, `artist`, `album`,
`title`, `playlist` (`controller/src/schemas/blocklist.ts`), до 50 правил по 12 значений, с
сезонным окном и привязкой к передачам. Хранятся в `state/blocklist.json`, отдельно от
`library.db`, чтобы сброс библиотеки их не стирал. Проверка — `blocklist.isBlocked()` в трёх
местах: общий фильтр всех песен из Subsonic (`subsonic.ts::rejectArchive`), источники из
`library.db` и вход в очередь `queue.push()`. Карточка правил —
`web/components/admin/library/BlockRulesCard.tsx`, у каждого правила счётчик «N tracks».

**Жанр сравнивается только латиницей, и молча.** `normGenre` —
`toLowerCase().replace(/[^a-z0-9]/g, '')` (`music/show-filter.ts:43`), граница слова в
`genreBoundaries` — та же (`:70`), и так же устроен `subsonic.resolveGenreName` (`:368`).
«Рок» превращается в пустую строку, пустая цель отбрасывается, и правило «Genre: Рок»
не блокирует ничего — со счётчиком 0 и без ошибки. По той же причине не работают
жанровые передачи с кириллицей; в журнале станции 35 пустых `songsByGenre("russian rock")`.

**Правило «Any tag» кириллицу понимает** — сравнивает строки целиком (`normText`). Это
обходной путь до выкатки: «Any tag: Рок» блокирует 1231 трек.

**Станция не знает, где лежит файл.** Navidrome отдаёт ей поддельный путь
`Артист/Альбом/Трек`: у плеера `sub-wave [node]` в базе Navidrome `report_real_path = 0`.
С флагом Navidrome 0.63.2 отдаёт **абсолютный** путь — `filepath.Join(LibraryPath, Path)`
(`server/subsonic/helpers.go:214`), то есть `<music-mount>/…`. В `library.db`
колонки пути нет. `MUSIC_LIBRARY_PATH` у станции не задан, поэтому `getLocalPath` не
работает и настоящий путь **не меняет воспроизведение** — станция играет потоком.

**Данные.** 4631 трек, без жанра у станции 1297. В тегах файлов пусто у 1293, но
жанр `Other` (4 файла) Navidrome жанром не считает, и станция видит его так же. Все
треки без жанра лежат в 13 плоских папках; числа — как их видит станция:

| Папка | Без тега | Размечено соседей |
|---|---|---|
| `Unsorted/!Помойка зарубежная` | 463 | — |
| `Сборки/_mus from vk/222` | 297 | Поп ×4, прочее ×3 |
| `Unsorted/!Помойка русская` | 237 | Поп ×5 |
| `Сборки/Europa Plus` | 220 | Pop ×38 |
| `Unsorted/Юля Кошкина` | 26 | — |
| `Сборки/Best of Eng Rock` | 17 | Rock (…) ×38 |
| `Сборки/Pop Best` | 9 | Pop ×33, Поп ×4 |
| `Unsorted/СЛОТ - ОркестрА` | 7 | — |
| `Unsorted/!Помойка Русский Рок` | 6 | Рок ×246 |
| `Сборки/_mus from vk/111` | 5 | Musical ×2, Поп ×1 |

| `Unsorted/Classic` | 3 | Classical ×11 |

В `Сборках` 866 треков, из них 798 повторяют трек из другой папки (артист + название);
своих нет только у «Детских песен из мультфильмов» (56) и «Июля 2023» (5) — владельцу они
в эфире не нужны. На копии из `Сборок` ссылаются четыре плейлиста: `Детские` (56),
`Favorite`, `Last` и `04. Д` (по 5).

## 3. Решение

### 3.1 Путь к файлу

- **Navidrome:** у плеера `sub-wave [node]` включается Report Real Path (админка Navidrome →
  Players). Остальные клиенты по-прежнему получают поддельные пути.
- **`library.db`:** новая колонка `tracks.path` — миграция следующим `user_version`,
  `ALTER TABLE … ADD COLUMN`, как все прежние. Путь пишется каждым `upsertTrackMeta`, у
  которого на руках песня из Subsonic, **и только абсолютный**: относительный (поддельный)
  путь не сохраняется и сохранённый не затирает.
- `library.get()` и `slimTrack()` отдают `path`; у песен из Subsonic он уже есть.
- Полная сверка (Admin → Library → Reconcile with Navidrome) заполняет путь у всех строк.

### 3.2 Жанр с кириллицей

`normGenre`, `genreBoundaries` и нормализация в `resolveGenreName` считают буквой и цифрой
любую букву и цифру Unicode (`\p{L}`, `\p{N}`). Латиница сравнивается как раньше
(`a-z0-9` — подмножество); латиница с диакритикой перестаёт терять буквы («Música» →
«música» вместо «msica») — одинаково с обеих сторон сравнения, поэтому совпадения не
ломаются. Побочный выигрыш — жанровые передачи с «Рок».

### 3.3 Жанр папки

- Таблица «папка → жанры» хранится в `state/folder-genres.json`, отдельным файлом рядом с
  `blocklist.json`: сброс и сверка библиотеки её не трогают.
- **Жанр трека** (`trackGenres`): жанры из тега, если они есть; иначе — жанры его
  собственной папки, а если ей ничего не назначено — ближайшего предка с назначением;
  иначе пусто. Тег всегда побеждает, даже мусорный (`Other`).
- Действует везде, где читается `trackGenres`: правила Genre и Any tag, жанровые замки
  передач, пометки блокировки в админке. **Не действует** на серверный поиск Navidrome по
  жанру (`getSongsByGenre`, инструмент агента `songsByGenre`): Navidrome знает только теги.
- Жанр передачи разрешается и в жанр папки (точное совпадение — после точного тега, до
  поиска по подстроке), а источник передачи добавляет к выдаче Navidrome треки папки —
  `controller/src/music/folder-genre-show.ts` (дописано 2026-10-09: без этого жанр,
  назначенный только папке, не разрешался, и замок передачи снимался целиком).
- Ключ — абсолютный путь папки без завершающего `/`.

### 3.4 Правило Folder

- `RULE_FIELDS` получает `folder`; значения — абсолютные пути папок, завершающий `/`
  срезается при сохранении.
- Трек подпадает, если его путь начинается с `значение + "/"` — граница по разделителю,
  поэтому `…/Сборки` не задевает `…/Сборки 2`.
- Путь трека — `track.path`, иначе `library.get(id).path`. Трек без пути не подпадает
  (недоблокировка, видна по счётчику из §3.5).
- Зеркало схемы для веба пересобирается `cd controller && npm run gen:schemas`.

### 3.5 Интерфейс вкладки Blocked

Подписи — по-английски, как вся админка (она не переводилась).

- **Редактор правила:** в «Match on» появляется **Folder**. Значения выбираются **деревом**:
  узлы сворачиваются, у каждого — число треков, строка поиска оставляет совпавшие узлы с их
  предками, флажок выбирает папку вместе с подпапками. Цепочка
  `<music-mount>` сворачивается в один корневой узел; в строке правила пути
  показываются от него.
- **Подсказки жанров** — жанры из тегов плюс жанры, назначенные папкам.
- **Новая карточка «Folder genres»** — то же дерево, по умолчанию только ветви с треками без
  тега. У такой папки — число треков без тега и жанры фишками (подсказки из тегов);
  сохранение отправляет таблицу целиком.
- **Предупреждение**, если у части треков нет пути: «N tracks have no real path — folder
  rules and folder genres can't see them». Так видно и выключенный флаг Navidrome, и
  несделанную сверку.

### 3.6 API контроллера

| Метод | Что |
|---|---|
| `GET /library/folders` | Каждая папка с треками и её предки: `{path, total, untagged, genres}`; плюс `withoutPath` — треков без пути |
| `GET /library/folder-genres` | Таблица целиком |
| `PUT /library/folder-genres` | Замена таблицы целиком. Отказ: путь не абсолютный, жанр длиннее 64 символов, больше 12 жанров у папки |
| `POST/PUT /library/blocklist/rules` | Принимают `field: 'folder'` |

`/library/genres` не меняется — им пользуются и другие экраны; подсказки склеивает карточка.

### 3.7 Стартовое наполнение

После выкатки, через API:

| Что | Значение | Ожидаемо |
|---|---|---|
| Правило Folder «Сборки — дубли» | `<music-mount>/Сборки` | 866 треков |
| Жанр папки `Unsorted/!Помойка русская` | Поп | 237 |
| Жанр папки `Unsorted/!Помойка Русский Рок` | Рок | 6 |
| Жанр папки `Unsorted/!Помойка зарубежная` | Pop, Rock | 463 |
| Жанр папки `Unsorted/Classic` | Classical | 3 |
| Жанр папки `Unsorted/СЛОТ - ОркестрА` | Рок | 7 |

Следствия, принятые владельцем:

- `Pop + Rock`: блокировка **любого** из двух жанров убирает всю папку, 463 трека, вместе с
  треками другого жанра. Разделить точнее можно только разметкой по артистам — отдельным
  шагом, если понадобится.
- Блок `Сборок` выбивает из передач по плейлисту записи, указывающие на копии оттуда:
  `Favorite`, `Last`, `04. Д` теряют по 5, `Детские` — все 56. Дубль в другой папке в эти
  плейлисты не входит.

## 4. Отказы

| Ситуация | Поведение |
|---|---|
| Флаг Navidrome слетел (новая строка плеера — флаг по умолчанию выключен) | Сохранённые пути не затираются поддельными; у новых треков пути нет — растёт `withoutPath`, карточка предупреждает |
| `folder-genres.json` испорчен | Старт с пустой таблицей и ошибкой в журнале — как у `blocklist.json`; эфир не останавливается |
| Папку переименовали или перенесли | Правило и назначение по старому пути совпадают с нулём треков — видно по счётчику |
| Откат контроллера на прежний образ | Прежний код отбрасывает правила с `field: 'folder'` как нечитаемые и при следующей правке списка перезаписывает файл без них. Перед откатом — копия `blocklist.json`. Лишняя колонка `path` прежнему коду не мешает: миграции идут только по `userVersion < N` (`music/library-db/schema.ts`), проверки «версия новее известной» там нет |

## 5. Проверка

- **Тесты контроллера** в стиле апстрима (`controller/scripts/*.test.ts`, `npm test`):
  кириллица в `normGenre` и `resolveGenreName`; `genreMatches` для «Рок»; жанр папки —
  ближайший предок, тег побеждает; правило Folder — граница по `/`; относительный путь не
  сохраняется и не затирает абсолютный; `folder-genres.json` — загрузка, отказ по
  валидации, испорченный файл.
- Полный набор тестов контроллера — сравнением с чистым клоном, как требует
  [README контроллера](../controller-changes.md): часть тестов апстрима
  краснеет и на чистом клоне.
- **Веб:** дерево — чистый модуль без React (построение из путей, свёртка корня, фильтр по
  поиску) с тестом через `tsx`, как `web/lib/roomRules.test.ts`; `npm run lint`.
- **Живая приёмка:** после сверки `withoutPath = 0`; «Folder: Сборки» — 866; временное
  правило «Genre: Шансон» — 42, «Genre: Поп» — 748 (511 по тегу и 237 по папке), затем
  удаляются; через несколько часов эфира в истории проигрываний нет ни одного трека из
  `Сборок`.

## 6. Выкатка

1. Navidrome: флаг у плеера станции; `getSong` отдаёт абсолютный путь.
2. Контроллер: правка в клоне → тесты → дифф исходников живого контейнера с клоном →
   сборка `1.8.0-ru` → подъём. Прежний образ перед сборкой сохраняется под отдельным тегом.
3. Сверка с Navidrome → `withoutPath = 0`.
4. Веб: зеркало схемы и интерфейс — в `ru-web.patch` → сборка → подъём.
5. Стартовое наполнение (§3.7).
6. Документация: раздел о блокировке в README станции, состав обоих патчей в их README,
   грабли в `CLAUDE.md` («жанр сравнивался только латиницей», «путь даёт флаг плеера
   Navidrome»).

## 7. Что не входит

- Жанровые передачи по расписанию и жанровые плейлисты в Navidrome.
- Правка тегов файлов.
- Разделение `!Помойка зарубежная` на Pop и Rock по артистам.
- Поиск Navidrome по жанру папки (`songsByGenre` агента).
- Перевод админки.

## 8. Риски

- **Патчи растут в местах, которые апстрим правит.** Контроллер — `show-filter`,
  `blocklist`, `library-db`, маршруты библиотеки; веб — `BlockRulesCard` и новые
  компоненты. Каждое обновление апстрима — больше конфликтов.
- **Флаг Report Real Path живёт в базе Navidrome**, а не в конфиге репозитория. Записан в
  README; дрейф виден по предупреждению о треках без пути.
- **Пути абсолютные:** смена точки монтирования обнуляет правила Folder и жанры папок —
  видно по счётчикам, чинится правкой путей.
